# AEV-001 — Temperature-only direct MLP

Status: initial validation complete; locked test not run. See [measured results](../results/AEV-001/README.md).

Hypothesis: a nonlinear model of the recent local temperature history improves multi-horizon accuracy over simple persistence on matched cases.

Protocol: see C001. Inputs are the last 24 hourly temperature bins, outputs are the next 24. Train using chronological training-only normalization and deterministic seeded initialization; tune on validation only. Freeze configuration before test scoring.

Record before execution: data snapshot hashes, split counts, exact optimizer settings and seed, git commit, baseline scores, neural scores, lead-wise errors, runtime and hardware. Do not fill results with synthetic numbers.

Acceptance: all baselines and model evaluated on identical eligible origins; publish skill even if negative.

## Initial validation recipe (predeclared)

Full 2000–2018 train and 2019–2022 validation only. Seed 42, Xavier initialization, tanh hidden layer of 32, linear 24-output layer, 10 epochs, shuffled SGD (deterministic xorshift), learning rate 0.005, normalized MSE. One scalar normalization fit to training input values and applied to both inputs and targets. Climatology: UTC month/hour mean of lead-one training labels, training global mean fallback. Report seasonal slices by first target's month. No test access. This is an initial fixed recipe, not an optimized architecture; changes must be tracked as separate validation configurations.

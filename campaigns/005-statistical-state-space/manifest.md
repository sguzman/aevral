# C005 — finite statistical/state-space campaign v1
Freeze before C005 fits. Fixed C003 cohort, Track A, 80 inputs, 72 chronological hourly temperature lags plus four calendar and four origin weather features. Model may ignore inputs. Training may use archive-derived parameters but every issued forecast gets only the same origin inputs and known future calendar, never future observations or future weather covariates. All filtering starts from the 72-hour observed window or a training-only prior; no state carried through earlier evaluation observations beyond that window. Full-history online filtering is deferred to Track B. Forecast 24 hours, recursively where the model naturally does so; scale using train only. Check exact cohort counts and daily baseline; reuse C003 MLP64.

## Implementation contract and order
1. S01–S04: stable centered one-step least squares (QR or numerically checked Gram). AR recursively shifts observed/predicted temperatures; ARX holds origin weather fixed during recursive forecast and recomputes calendar from origin+lead, training uses origin covariates for next step. Label frozen-weather approximation. VAR uses five observed state components at origin, VARX adds known calendar; fit next state from adjacent training origin rows exactly 60 minutes apart, never crossing discontinuities or split boundaries. Joint recursion predicts all state variables; report number of usable transitions. VAR orders >1 inapplicable in Track A (no causal per-origin historical covariates). Reject nonfinite trajectories; disclose unstable roots/diagnostics, no forecast clipping.
2. S05–S07: genuine conditional ARMA innovation recursion, differencing/integration as specified; multiplicative seasonal polynomial cross terms and period24. Initialize conditional residuals from observed 72-hour window only; no future innovations (zero conditional expectation). Fit stationary/invertible parameters via deterministic bounded conditional sum-of-squares on train-only windows and document optimization tolerance, exact objective and fit sample in batch specification before running. Exogenous regression with fixed-at-origin weather and known calendar; never relabel plain AR as ARIMA. Limited window means conditional likelihood approximation, not exact full-series ML. If unavailable or numerically unstable, explicit block.
3. S08–S11: actual additive ETS innovations, harmonic regression with recursively forecast AR residuals, explicit structural Gaussian transition/observation equations and causal Kalman updates for stochastic level/trend/seasonal and dynamic harmonic coefficients. Fit smoothing/noise parameters using train-only one-step losses/likelihood, deterministic bounded grid or optimization predeclared per batch. Initial states from first observations in window or training-only prior; observe/filter through origin, predict without assimilation. Verify covariance PSD and finite innovations; no smoothing in forecast path. Distinguish state-space filtering from static regression.
4. S12: two-state transition matrix, regime-specific AR emissions, filtered regime posterior and future regime probabilities. Deterministic initialization and constrained EM or conditional likelihood, documented convergence; forecast joint regime/state expectation (or explicitly labeled bounded approximation), no future observations. S13: genuine GARCH variance recursion with positive parameters and alpha+beta<1, innovations from AR; point mean unchanged, assess uncertainty via NLL/coverage, explicitly approximate multi-step variance if needed.
5. Before each batch commit exact equations, training-only sample/optimization budget, tolerances, parameter count conventions and tests. Synthetic known AR/VAR, differencing round-trip, seasonal cross terms, innovations, covariance, regime and variance tests as applicable; causal invariance to evaluation target mutation, no evaluation rows in fit. All CI jobs <=30min, <=6 parallel, <=2GB workspace target; preflight expensive algorithms, preserve hashes and logs; no paid compute, new data, local downloads or 2023–26 access. No use of future evaluation scores to alter manifest. No external packages unless pinned and justified.

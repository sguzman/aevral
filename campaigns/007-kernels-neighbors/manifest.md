## Mathematical and implementation contracts

- Distance: d²(x,z)=sum_j (x_j-z_j)^2/80 over original normalized features; RBF k=exp(-d²/(2*l²)). No learned metric or per-fold evaluation tuning. Deterministic distance/index ties; exact brute-force neighbors within reference subset, not approximate search. All methods learn from paired historical origins and their already-observed 24-hour targets.
- K01 arithmetic mean of k target vectors. K02 inverse distance w=1/max(sqrt(d²),1e-8), or exp(-d²/(2*max(d²_k,1e-12))) with kth-neighbor scale. Exact zero-distance matches take precedence and average among selected exact matches. Normalize weights. K03 restrict using calendar sine/cos pairs (indices 72–73 hour, 74–75 year), wrapped phase distance <=2h and <=15/30 equivalent days of a 365-day cycle. Rank remaining by d² and uniform average their full following 24-hour trajectory. If fewer than k candidates use all; if none, nearest unrestricted neighbor and record fallback count, not an evaluation exclusion. Record min/mean candidate counts.
- K04 nearest k as above, centered local offsets z−x on predeclared coordinates 23,47,65,71,72–79 (12 dims, original Track A only). Fit a shared design with 24 output columns by weighted-free ridge, sum squared error/k + lambda * slope norm², intercept unpenalized; forecast at zero offset. All 80 features still define neighbor distance. Cholesky solve with finite/positive-definite checks; no global regression substitution. Report local solve failures explicitly.
- K05 linear kernel (dot/80) exact primal ridge on x/sqrt(80), centered features and targets with training-only intercept. Objective mean squared error + lambda*norm², shared solve 24 RHS; equivalently dual diagonal n*lambda. K06 exact dense RBF ridge on selected rows, center targets by training sample mean, solve (K+lambda I)alpha=y−mean, add mean back. Here lambda denotes diagonal regularization, not mean-loss penalty. Cholesky, residual diagnostics; no O(N²) full archive allocation.
- K07 use actual official LIBSVM epsilon regression, RBF gamma=1/(160*l²), C as listed, epsilon=.05 in normalized target units, solver tolerance .001, shrinking enabled, cache 128 MiB, no probability fit; independent scalar models per horizon. Use 80 numeric features, no label leakage, validate support-vector counts, predictions, finite values, and synthetic epsilon-tube behavior. Pin/probe installed LIBSVM through flake.lock; if CLI absent, use official pinned library API if available, otherwise report blocked rather than substitute another algorithm. Exact trained subset; no claim of full archive SVR.
- K08 zero-mean GP after sample target centering, unit amplitude RBF prior, Gaussian noise variance .05, fixed jitter 1e-8. Shared kernel Cholesky over 1024 rows, 24 independent scalar outputs with shared covariance. Compute latent posterior mean and latent variance k(x,x)−k_x^T(K+noise I+jitter I)^−1 k_x; report variance on deterministic first 32 evaluation inputs as a numerical diagnostic, not calibrated uncertainty. Point mean algebraically equivalent to KRR with the same diagonal penalty; explicitly distinguish objective/variance, not claim inherently different point predictions.
- K09 FITC approximate GP, deterministic evenly spaced inducing rows chosen from the 8192 reference subset, Kmm with 1e-8 jitter, q_i=k_im Kmm^-1 k_mi, D_i=max(0,1−q_i)+.05; A=Kmm+Kmn D^-1 Knm; posterior mean k_xm A^-1 Kmn D^-1 (y−mean)+mean. Latent variance 1−k_xm Kmm^-1 k_mx+k_xm A^-1 k_mx, diagnostic first32; bound negative diagonal/variance roundoff, reject material violations. Stream weighted sufficient statistics, no n×n matrix. FITC, not full exact GP nor renamed KRR.
- K10 random Fourier map sqrt(2/m)*cos(w^T x+b), independent w_j~Normal(0,1/(80*l²)), b~Uniform[0,2pi). Seeded SplitMix64 + Box–Muller, frozen draw order, ridge mean-loss .01 on centered feature/target maps, intercept unpenalized. Report actual m, seed, kernel approximation diagnostics on deterministic training pairs; three-seed evaluation required.
- K11 Nystrom map z=L^-1 k_mx where LL^T=Kmm+jitter I, evenly spaced deterministic landmarks from subset. Center mapped rows/targets; ridge mean-loss .01, exact Cholesky primal fit on approximate feature map. Report landmark count and kernel approximation diagnostic. Distinct from FITC diagonal correction and posterior variance.
- Shared numerical tests: hand-computed distances and exact tie/zero cases, wrap-around seasonal filter, local affine recovery and rank-deficient ridge, dense Cholesky residual and diagonal failure, linear primal/dual parity, RBF kernel symmetry and positive definiteness, exact GP predictive mean/variance and FITC exact-inducing limit, RFF reproducibility and Nystrom full-landmark Gram reconstruction, no target leakage. Tests before real data. Track sample counts, model dimensions, resource usage, elapsed fit/predict time, preflight estimate, full per-lead and per-month errors; preserve scores and artifacts per C003.

# Official backend preflight
No model fit or version claim yet. Probe each official upstream backend on hosted CI against the exact nixpkgs revision in flake.lock. Check top-level and python3Packages derivations for availability of CLI or shared-library outputs; the latter is a discovery path only, not approval to depend on Python at runtime. Each build probe capped at 360 seconds; three independent jobs, <=30min/job. Capture version, outputs, executables, CLI help, shared libraries and errors. A timeout alone does not establish absence. If no usable interface is exposed, inspect feasible checksum-pinned upstream release/source derivation. Freeze real backend versions and interfaces before any fit. No local downloads, new weather data, or substitute implementations.

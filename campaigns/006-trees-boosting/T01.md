# T01 exact CART batch
Six deterministic configurations per manifest, fixed 24576 evenly spaced train origins; all 80 features, normalized 24 outputs. For each node sort row IDs by (feature value, row ID), scan each distinct adjacent boundary with both children >=min leaf. Gain = ||sum_left||²/n_left + ||sum_right||²/n_right - ||sum_parent||²/n_parent, equivalent to summed SSE reduction. Threshold is observed left maximum, <= left, not midpoint (same training partition; explicit inference convention). Choose first feature/ascending boundary for ties within 1e-12; require gain >1e-10. Stop at depth, insufficient rows, constant target or no legal gain. Leaf means. Shared output uses one vector-valued tree; per-lead uses 24 independent scalar trees. Fit guard 1200s, root split timing preflight conservative estimate root*(1+2*depth*number_trees); reject if above guard. Node/leaf counts, scalar leaf output count (not including split metadata), elapsed, score/lead/month, RSS. No random seed. Five numerical tests. Six jobs at most six parallel. No new data.

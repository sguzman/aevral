# T05/T09 histogram boosting batch
Six frozen deterministic configs: hist-32-d3/hist-64-d3/hist-32-d5/hist-64-d5 (squared loss), median-boost-32/64 (depth3, median pinball). All use 24576 evenly spaced training origins, 80 inputs, shared topology across 24 normalized outputs, minimum 32 rows per leaf, learning rate 0.1. Train-only quantile bin cuts at sorted index floor(b*n/32)-1, b=1..31, deduplicate and omit max; <=cut routes left, identical bin/prediction rule. Binned gradient SSE gain ||sum_l||²/n_l+||sum_r||²/n_r-||sum||²/n; positive gain >1e-10, stable first feature/cut ties. Squared loss initializes per-lead mean, fits residual means. Pinball initializes per-lead median (average central two if even), gradient +0.5/-0.5/0 by residual sign, fits shared gradient split topology then per-lead median of actual residuals in each leaf (not sign means), shrink 0.1. Log normalized training objective (MSE or half absolute residual) each stage. No validation-based stopping. First stage preflight 2x extrapolation, 1200s guard, no adaptive stage changes. Six tests cover bin boundaries, shared split, median, subgradient, min leaf/constant, shrinkage. Scalar leaf output count includes initialization vector; excludes split metadata. Six CI jobs, no new data.

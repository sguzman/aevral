# T02–T04 forest batch
Ten predeclared configurations, shared 24-output CART depth8 leaf32. Training sample same deterministic 24576 rows as T01. Bagged trees use full 80-feature exact SSE scan; random forest uses 9/27 features drawn uniformly without replacement per node via partial Fisher–Yates, sorted before testing, bootstrap n rows with replacement per tree (duplicates count toward leaf minimum). Extra Trees uses same feature subset and no bootstrap, one uniform threshold between observed min/max for each nonconstant selected feature, reject illegal child sizes, select maximum positive SSE gain; no redraw if candidate illegal. SSE gain identical to T01; exact CART splitter unchanged apart from explicit feature-list argument. SplitMix64 stream, unbiased rejection for bounded integers, 53-bit uniform for thresholds; seed42 screen, 42/123/2026 finalist; deterministic tree order, arithmetic mean of leaf vectors. Fit first full tree, estimate remaining cost with 2x headroom, hard elapsed guard1200s. No adaptive tree count, no evaluation data in fitting. Five additional tests (bootstrap reproducibility, feature uniqueness, Extra Trees reproducibility/valid split, exact bagged split). Model diagnostics include seed, counts, mtry, bootstrap/random-threshold flags, nodes, leaves, scalar leaf values, elapsed. Ten jobs, maximum six parallel. No new data.

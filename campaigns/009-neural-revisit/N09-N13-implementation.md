# N09–N13 implementation notes

Frozen recipes unchanged. All affine weights initialized in layer order, row-major, xorshift64 high53 Xavier; biases zero, no parameter allocation for biasless projections. Block forecast interpolation uses exact rational index t*(k−1)/23 and its adjoint; final backcast is computed but has zero loss gradient since no later block consumes it. TiDE bottleneck linear; residual outer path identity, ReLU inner, tanh stem and decoder, independent biasless temperature skip. DLinear trend and residual affine with separate biasless covariate projection; NLinear translation-equivariant temperature offset, optional output bias. Gradient checks absolute 1e−6 on sampled input/middle/end parameters in first/middle/last rows of every tensor; invariant and small-fit checks. Workspace upper bound remains conservative for these compact models. No official upstream implementation claim.

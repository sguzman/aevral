# N14–N15 implementation notes

Frozen dimensions and recipes unchanged. Q/K/V each affine d→d, contiguous equal-size head slices, per-head softmax, scale 1/sqrt(head dimension). PatchTST-style concatenates heads, output affine, residual then affine layer norm; ReLU feed-forward, residual and second affine layer norm. Norm epsilon 1e−5, gain initialized to one and bias zero; exact population variance gradient. N15 reproduces legacy tanh-after-residual encoder without output projection or norms. Xavier draws layer order, row-major then learned positions. Norm parameters initialized deterministically. Legacy module untouched, compatibility tested against original p6/d8 forward. Sampled gradients in every weight group, positions and affine norms, tolerance 2e−6. Workspace bound covers maximum 24 observed patches and two 24×24 softmax matrices. No upstream official implementation claim.

# N16–N17 implementation notes

Frozen recipes unchanged. Diagonal state-space alpha sampled uniform ±1 first, then scalar drive Xavier uniform sqrt(6/(1+h)), zero drive bias, affine head sampled row-major. BPTT differentiates sigmoid decay, drive and bias at every step. No S4/Mamba claim. Mixture gate affine initialized first, then independent experts in index order, row-major Xavier and zero biases. Softmax uses maximum subtraction; all experts and gate receive exact loss gradients. Gradient norm clip 5 across all weights. Central finite differences at sampled first/middle/last weights in every parameter group, absolute tolerance 1e−6. Tests include closed-form constant-input recurrence, normalized strictly positive gates and convex combination, deterministic seed and overfit. Existing workspace upper bound covers 73×32 states and up to four expert caches.

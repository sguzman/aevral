Shared triangular factor reused across all seven configurations. Ridge is equivalent to adding sqrt(n*lambda) identity rows except intercept. Back substitution; diagonal relative tolerance 1e-10 for full rank, fail explicitly on rank deficiency, no minimum-norm pseudoinverse claimed. Report min/max absolute diagonal ratio as diagnostic, NOT a condition number or effective rank estimate for arbitrary ill-conditioned designs; non-pivoted QR. Factor and per-config solve time separately reported; total standalone fit cost = shared factor time + solve time. 1944 coefficients, intercept included. Tests exact synthetic coefficients, analytic ridge shrinkage, intercept invariance, prediction restoration and rank failure. Frozen 2019 counts and baseline checked.
